## PRODUCTION TIPS

### Equipment
- **Phone:** Use latest iPhone/Android (good screen recording)
- **Screen recording:** Built-in screen record + audio from calculator
- **Voiceover:** Use phone microphone or USB mic
- **Editing:** CapCut (free, mobile + desktop)

### Editing Workflow
1. Screen record calculator (1–2 minutes)
2. Cut to key moments (remove dead time)
3. Add captions (CapCut auto-generates, then edit)
4. Add background music (royalty-free from CapCut library)
5. Color grade (increase contrast, boost gold brand color)
6. Add CTA at end (text + button mock-up)
7. Export (1080×1920 for Reels/Shorts, square for TikTok)

### Captions
- Keep text on screen for 2–3 seconds minimum
- Use white text with dark shadow for visibility
- Highlight key numbers in **GOLD (#f5a623)** — matches brand
- Use emoji sparingly (max 2 per video)

### Audio
- Voiceover: Clear, conversational, 1.5x speed (no monotone)
- Background music: Upbeat, financial/tech theme (royalty-free)
- Sound effects: Subtle coin/cash sounds when numbers appear (not annoying)

### Call-to-Action
- Always end with: "Link in bio" or "Open the app"
- Vary CTAs: "Try it free," "See your number," "Calculate now"
- Include calculator URL or app link
